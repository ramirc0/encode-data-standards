# ChIP-seq

[Root](../../README.md) / [DNA binding](../README.md) / ChIP-seq

Chromatin immunoprecipitation followed by sequencing. ENCODE runs two pipelines and sets standards by target class.

- [Transcription factor](transcription-factor/README.md): [ENCODE4](transcription-factor/encode4.md), [ENCODE3](transcription-factor/encode3.md)
- [Histone](histone/README.md): [ENCODE4](histone/encode4.md), [ENCODE3](histone/encode3.md)
- [ENCODE2](encode2.md): TF and histone standards from the ENCODE2 sections of the pages, Landt et al. 2012 and the 2008, 2010 and 2011 standards documents
- [Experimental guidelines](experimental-guidelines.md): ENCODE3 ChIP-seq guidelines, January 2017 (listed as current)
- [Portal audits](portal-audits.md): read depth, library complexity, IDR, read length and control cutoffs in the portal code

Related: [antibody standards](../../antibodies/README.md), [cell culture](../../general/cell-culture.md), [ChIP-chip](../chip-chip.md).
