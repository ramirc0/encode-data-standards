# Antibodies

[Root](../README.md) / Antibodies

ENCODE characterizes each antibody lot before its data can count as standard. A lot passes a primary method (an immunoblot, or an alternative such as IP mass spec) and usually a secondary method (knockdown, a second antibody, motif enrichment, and others). Each characterization gets a [status](../GLOSSARY.md#antibody-characterization-status). Except for histone modifications, a lot must be characterized in each cell type and species where it is used ([antibody characterization process](../sources/pages/help__antibody_characterization_process.md)). The portal enforces eligibility through the [antibody audits](../audits/README.md#antibody-characterization).

## Current standards

The [experiment guidelines page](../sources/pages/about__experiment-guidelines.md) lists these.

| Leaf | Targets | Date |
|---|---|---|
| [Transcription factor](transcription-factor.md) | Endogenous TFs for ChIP-seq | May 2016 |
| [Histone and chromatin-associated](histone-chromatin.md) | Histone variants, histone modifications and chromatin-associated proteins for ChIP-seq | October 2016 |
| [RNA-binding protein](rna-binding-protein.md) | Endogenous RBPs | November 2016 |
| [fRIP](frip.md) | Chromatin-associated proteins in fRIP assays | November 2016 |
| [Epitope-tagged TF](epitope-tagged-tf.md) | Tagged TFs, co-factors and chromatin-associated proteins for ChIP-seq | August 2019 |
| [Epitope-tagged TF (2017)](epitope-tagged-tf-2017.md) | The same scope, listed under experiment guidelines | January 2017 |

The August 2019 document supersedes the May 2016 TF standard "concerning epitope tagged datasets". No document says it supersedes the January 2017 one.
