# Small RNA-seq Data Standards and Processing Pipeline

### Assay Overview

There are many classes of small RNAs (tRNAs, microRNAs, miRNA, snoRNAs, etc…) less than 200 nucleotides in length, each of which carries out distinct biochemical roles in the cell.  These roles may include messenger RNA interference silencing and degredation, among others. These RNAs can be captured and sequenced using a variety of methods to enrich for various classes.

### Pipeline Overview

The small RNA-seq pipeline was developed as a part of the [ENCODE Uniform Processing Pipelines](https://www.encodeproject.org/pipelines/) series. The full pipeline code is freely available on [Github](https://github.com/ENCODE-DCC/long-rna-seq-pipeline/tree/master/dnanexus/small-rna) and can be run on [DNAnexus](https://platform.dnanexus.com/projects/BKpvFg00VBPV975PgJ6Q03v6/data/) (link requires account creation) at their current pricing.

The ENCODE RNA-seq pipeline for small RNAs can be used for libraries generated from rRNA-depleted total RNA that are size-selected to be shorter than approximately 200 nucleotides. Data may be paired-ended and stranded or single-ended and unstranded.

### Uniform Processing Pipeline Restrictions

- The read length should be a minimum of 50 base pairs.
- Sequencing should be single-ended.
- All Illumina platforms are supported for use in the uniform pipeline; colorspace (SOLiD) are not supported.
- Barcodes and [spike-in sequences](https://www.encodeproject.org/references/ENCSR999FPQ/), if present in the fastq, must be indicated in the flowcell metadata.
- Library insert size range must be indicated.
- Alignment files are mapped to either the [GRCh38, hg19, or mm10](https://www.encodeproject.org/references/ENCSR425FOI/) sequences.
- Gene and transcript quantification files are annotated to either [GENCODE V24, V19, or M4](https://www.encodeproject.org/references/ENCSR884DHJ/).

### Current Standards

Experimental guidelines for small RNA-seq experiments can be found [here](https://www.encodeproject.org/about/experiment-guidelines/).

- An small RNA-seq experiment is an RNA-seq assay in which the average library insert size is \<200 base pairs.
- Experiments should have two or more [replicates](https://www.encodeproject.org/data-standards/terms/#quality-metric-def). Assays performed using EN-TEx samples may be exempted due to limited availability of experimental material.
- Each replicate should have 30 million [aligned reads](https://www.encodeproject.org/data-standards/terms/#read-depth), although older projects aimed for 10 million [aligned reads](https://www.encodeproject.org/data-standards/terms/#read-depth). Best practices for ENCODE2 RNA-seq experiments have been outlined [here](https://www.encodeproject.org/documents/91494746-0ffe-4931-b219-a09802ce1cfa/@@download/attachment/RNA_standards_v1_2011_May.pdf).
- Replicate concordance:the gene level quantification should have a [Spearman correlation](https://www.encodeproject.org/data-standards/terms/#concordance) of \>0.9 between isogenic replicates and \>0.8 between anisogenic replicates (i.e. replicates from different donors).
- The experiment must pass routine metadata audits in order to be released.
