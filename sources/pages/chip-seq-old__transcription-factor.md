# ChIP-seq of Transcription Factors

### ENCODE3 Standards

- Experiments must have two or more biological replicates, isogenic or anisogenic. Replicates must match in terms of read length and run type. 
- The minimum read length is 50 base pairs, though longer read lengths are encouraged.
- Each experiment should have 20 million usable fragments per replicate for single-ended data and per mate pair for paired-ended data. 
- Antibodies must be characterized according to [standards set by the ENCODE Consortium](https://www.encodeproject.org/documents/e7c46221-861b-4687-ab2c-6c5269223c5c/@@download/attachment/Antibody_Characterization_ENCODE3_August2015.pdf)
- Each ChIP-seq experiment should have a corresponding control experiment with matching run type, read length, and replicate structure. 
- Replicate concordance is measured by calculating [IDR values](https://www.encodeproject.org/data-standards/#quality-metric-def) (Irreproducible Discovery Rate). The experiment passes if both rescue and self consistency ratios are less than 2.
- Library complexity is measured using the [Non-Redundant Fraction (NRF) and PCR Bottlenecking Coefficients 1 and 2, or PBC1 and PBC2](http://www.encodeproject.org/data-standards/#quality-metric-def). Preferred values are as follows: NRF\>0.9, PBC1\>0.9, and PBC2\>10.
- The sequencing platform used must be indicated, and the experiment must pass routine metadata audits in order to be released.

### ENCODE2 Standards

Data quality standards for ENCODE2 are outlined in [ChIP-seq guidelines and practices of the ENCODE and modENCODE consortia](https://www.encodeproject.org/publications/1f43e24e-7b18-4af6-8cfa-a5753500d8bc/) 

- Experiments must have two or more biological replicates, isogenic or anisogenic. Replicates must match in terms of read length and run type. 
- The minimum read length is 36 base pairs, though longer read lengths are encouraged.
- Each experiment should have 10 million usable fragments per replicate for single-ended data and per mate pair for paired-ended data. 
- Antibodies must be characterized according to [standards set by the consortium for ENCODE2 data](https://www.encodeproject.org/documents/e82fdfdf-f387-47d8-af03-df67bbea0e72/@@download/attachment/2010-05-30_mod-ENCODE_TF_Chrom_Data_Standards.pdf).
- Each ChIP-seq experiment should have a corresponding control experiment with matching run type, read length, and replicate structure. 
- Replicate concordance is measured by calculating [IDR values](http://www.encodeproject.org/data-standards/#quality-metric-def) (Irreproducible Discovery Rate). The experiment passes if both rescue and self consistency ratios are less than 2.
- Library complexity is measured using the [Non-Redundant Fraction (NRF) and PCR Bottlenecking Coefficients 1 and 2, or PBC1 and PBC2](http://www.encodeproject.org/data-standards/#quality-metric-def). Preferred values are as follows: NRF\>0.9, PBC1\>0.9, and PBC2\>10.[ ](http://www.encodeproject.org/data-standards/#quality-metric-def)
- The sequencing platform used must be indicated, and the experiment must pass routine metadata audits in order to be released.
